## 先分清：你要的是云 VPS 还是独立服务器

搜“海外服务器租用”的人，实际要的东西分两类。一类是建站、挂应用、跑 Docker 的，云 VPS 就够了，弹性、便宜、坏了能迁移；另一类是跑游戏服、数据库、虚拟化宿主机的，需要独占整台物理机的性能，那就是裸金属独立服务器。

## 三个容易踩坑的细节

这几条来自官方 FAQ 和页面说明，多数测评文章不会写到，但每一条都可能影响你的实际体验。

**第一，10Gbps 是连接速度，不是保证吞吐。** 官方原话是端口容量指连接速度，实际吞吐取决于流量路径和工作负载。你在速度测试里跑不满 10Gbps 属于正常现象，别拿这个去跟商家扯皮。同理，300TB 月流量对应的是端口带宽下的流量额度，超量或限速规则以订单条款为准。

**第二，Public Cloud 的“资源上限”不是消费上限。** 这是官方 FAQ 里明确澄清的一条：Small、Medium、Large 档有资源天花板，但超出基础费的部分会按公布费率计费，资源上限并不会封顶你的账单金额。想要账单完全可预测，选 Dedicated Cloud，固定资源固定价格，没有自动超额——很多人把这两个概念混着用，结果月底收到意外账单。

**第三，Dedicated Cloud 和 Private Cloud 是两个产品。** Dedicated Cloud 是固定资源分配的云服务；Private Cloud 是专属物理基础设施。要独占整台物理机，看的是 Bare-Metal 或者 Private Cloud，别在 Dedicated Cloud 页面里找不到“独占硬件”就觉得被骗了。
